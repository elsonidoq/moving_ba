# Photographic mockup index

This directory contains the conceptual Spanish-language photographic mockup and its reference assets. It is a visual/product reference, not a live service contract.

## Direct files

- [Usage notes](LEEME.md): Spanish instructions, demonstrated flows, scope, and source notes.
- [Interactive mockup](index.html): standalone HTML/CSS/JavaScript presentation of the photographed demo flows.
- [Photo gallery](galeria_fotos.html): visual catalog of the 29 referenced photographs and their source links.
- [Photo source table](fuentes_fotos.csv): machine-readable photo identifiers, descriptions, source URLs, and local filenames.
- [Photo downloader](descargar_fotos.py): optional script that retrieves the manifest-listed JPEG files for offline mockup use.

## Asset directories

- `assets/`: image manifest and the mockup's local JPEG files. These are reference/runtime assets rather than a child documentation directory.
